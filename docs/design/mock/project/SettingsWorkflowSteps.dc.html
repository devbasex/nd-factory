モード
変更の種類ごとに通す工程の量を決めます
light
文言・設定値・テストの追加など、振る舞いを変えない小さな変更
operation
コードを変えず、外部の系の状態だけを変える操作
legacy-refactor
テストの少ないコードの構造だけを変える変更
standard
振る舞い・API・認証などを変えるふつうの開発
documentation
提案資料・報告など、外の読み手へ渡す文書
該当時
条件に当たるときだけ通す工程
