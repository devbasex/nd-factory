新しいアカウントで各画面を開いたときに出す、空の表示と次にすることです

/repositories リポジトリ
まだリポジトリがありませんAI が作業する GitHub のリポジトリを登録すると、ここからスプリントを始められますリポジトリを連携する
/plans 開発計画
開発計画はまだありません複数の課題をレーンに分けて並行して進めたいときに作ります。1 つずつなら、スプリントだけで足ります開発計画を作る
/sprints スプリントの一覧
スプリントはまだありませんスプリントは、AI が 1 つの課題を設計からリリースまで進める 1 回の実行ですスプリントを始める
/loops ループ
ループはまだありません順位の高い課題から自動でスプリントを続けます。予算（周回・費用・時間）で止まりますループを始める
/factory/machines マシンと実行
動いている実行はありませんスプリントかループが動き出すと、どのマシンで動いているかがここに木で出ます自分の PC を登録する
/approvals 承認待ちの一覧
承認待ちはありませんAI があなたの判断を必要とすると（設計の承認・本番へ出す承認）、ここに出て Slack にも届きます通知を設定する

空の表示は「何が無いか」「それは何か（1 文）」「次にすること（主の操作 1 つ）」の 3 つで書く。主の操作を押せない役割（席）には、押せる人を書いた 1 行を出す
