# NDF との契約の付け替え（#41）の経緯

このディレクトリは、全体の設計の「NDF との契約」と固定の点（`ndf-pin.json` の `ndf_ref`）を、配布された ndf v11.0.12 の契約（版 8・`plugins/ndf/contracts/`）へ付け替えたときの設計の記録の置き場である。受ける契約の組・置き場・口と引数の名前・区間の報告の決まりの出所・契約の照合の定期の検査が読む先を、どう決めたかと、その理由（決定 104〜108）を残す。

付け替えた後の設計そのものはここに無い。正は [`docs/design/`](../../design/overview.md) で、NDF との契約は [実行の文書の NDF との契約](../../design/execution.md#ndf-との契約) と、その「決定の記録」の決定 104〜108 にある。使う NDF のコミットの正は `ndf-pin.json` である。ここの文書と食い違えば `docs/design/` と `ndf-pin.json` が勝つ。ここの文書は付け替えた後に追わない。
